# Artskonsekvens – byggbevaring

Tidlig screening av arter og natur i et utbyggingsområde. Tegn tiltaksområdet på kartet, så henter siden rødlistede arter og fremmedarter fra Artskart, naturtyper og verneområder fra Naturbase og artsrikdom fra GBIF. Den lager et førsteutkast til konsekvensvurdering per art etter M-1941 (verdi × påvirkning) og foreslår tiltak etter tiltakshierarkiet (unngå, avbøte, restaurere, kompensere).

Siden er én HTML-fil (`index.html`) uten byggesteg. Den kan åpnes lokalt eller publiseres med GitHub Pages.

**Forbehold:** Dette er en automatisk screening, ikke en konsekvensutredning. At det ikke finnes registrerte funn, betyr ikke at arter mangler.

Datakilder: Artskart (Artsdatabanken), Norsk rødliste for arter 2021, Fremmedartslista 2023, Naturbase (Miljødirektoratet), GBIF, Kartverket.
